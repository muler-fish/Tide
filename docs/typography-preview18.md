# preview.18 · 全应用 MiSans 字体

日期：2026-10-26。按用户“统一字体”的选择，主界面、正文、发言编辑器、颜文字下拉和子窗口共用 MiSans。TODO 第 5 项仍待验收；第 7 项的大型图案跨设备对齐和彩色 emoji 不记为完成。

## 字体与体积

仅嵌入需要的 TTF 文件，不安装系统字体，不裁剪或修改原字库。五个文件与用户压缩包中的原文件逐字节一致，校验记录见 `artifacts/misans-original-hashes.json`。

| 文件 | 用途 | 原始大小 |
| --- | --- | ---: |
| MiSans-Regular.ttf | 普通中文、拉丁文字和数字，版本 4.009 | 8,122,324 字节 |
| MiSans-Semibold.ttf | 标题与强调文字，版本 4.009 | 8,034,980 字节 |
| MiSansThai.ttf | 颜文字中的 `ฅ`、`ง`、`ว`，版本 1.000 | 46,660 字节 |
| MiSansLao.ttf | 颜文字中的 `໒`，版本 1.000 | 43,008 字节 |
| MiSansTibetan-Regular.ttf | 颜文字中的 `༝`，版本 1.000 | 482,056 字节 |

前两项来自 `MiSans.zip`，后三项来自 `MiSans_Global_ALL.zip` 的对应语言包。新增 MiSans 字体合计 16,729,028 字节，其中 Global 三份补充文件合计 571,724 字节，约 0.55 MiB。

Global 包不是单一字体。检查其中各语言常规或默认字重的字符表后，选用上述三份补充文件；Latin、繁体 TC、扩展汉字 L3 等未为当前颜文字库提供所需的新增字形，没有打入应用。Global 内的基础 MiSans 是 4.003，因此保留之前压缩包中较新的 4.009。

打包实测：preview.17 EXE 为 67,685,038 字节（64.55 MiB）；preview.18 为 78,857,444 字节（75.20 MiB），增加 11,172,406 字节（10.65 MiB）。不包含两个原始压缩包，也不包含其他字重、OTF、网页字体或可变字体。随包另附小体积许可证文档。

## 回退与排版

- `AppFonts.cs` 提供唯一文字字体入口，`App.xaml` 的应用字体和 WPF UI 文字资源共同引用它；颜文字弹出层也显式继承同一入口。
- `TideReading.CompositeFont` 优先使用 MiSans，按文字区段选取 Thai、Lao、Tibetan；MiSans 未覆盖的字符继续使用备用字体。
- `ᝫ`（U+176B）、`ᯅ`（U+1BC5）在这份 Global 常规字重中仍缺失，继续使用内嵌的 Noto Sans Tagbanwa / Batak。
- “手枪”“撞墙”等组合字符不能仅按缺失字符回退：WPF 会先按基字符选择字形。将 U+0020 空格、U+002F 斜线、U+003D 等号、U+2019、U+200B 与相关组合附加符号交给 Segoe UI，避免基字符存在但附着符号变成 glyph 0。中文、英文字母和数字仍由 MiSans 绘制。
- 图标继续使用 WPF UI 的 Fluent 图标字体。颜色、字号、行高、窗口尺寸规则和交互保持原有设置。
- 不重写用户正文，不改变颜文字内容；preview.17 对字库里一个组合符号的零宽基底兼容处理继续保留。

字体一致性不等于所有大型 AA 图案严格对齐：比例字体、备用字形和原始空白都会影响图案。当前没有实现彩色 emoji 渲染，TODO 第 7 项仍开放。

## 许可与技能

本软件使用 MiSans 字体。保留字体中的版权信息，并在设置中提供简短署名；完整协议与来源说明放在源码 `docs/licenses/` 和发布目录 `licenses/`。协议依据：[小米官方 MiSans 字体知识产权许可协议](https://hyperos.mi.com/font-download/MiSans%E5%AD%97%E4%BD%93%E7%9F%A5%E8%AF%86%E4%BA%A7%E6%9D%83%E8%AE%B8%E5%8F%AF%E5%8D%8F%E8%AE%AE.pdf)。原有 Noto 的 SIL OFL 许可继续随包交付。

使用 `ui-ux-pro-max` 的字体层级、跨主题一致性与输入内容可见性检查；用户指定的 MiSans 与现有桌面交互优先，不套用网页布局或额外增加装饰。
