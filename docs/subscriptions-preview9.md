# 潮汐 preview.9 · 通用订阅

日期：2026-10-23。基于 WPF + WPF UI 4.3.0，按用户决定移除本地串收藏，直接接入 X 岛通用订阅；不保留旧串收藏，也不提供迁移功能。版块收藏仍为本机导航快捷入口。

## 使用方式

- 左侧“我的订阅”展示当前订阅号的云端串列表，进入时自动刷新，也可按 F5 刷新。
- “我的订阅 → 订阅号”或“阅读设置 → 管理订阅号”可以导入、新建和复制号码。
- 第一次使用自动生成随机 UUID。已有手机端订阅号时，粘贴原号码并点击“使用此订阅号”；大小写保持原样。
- 串右上角星标及 Ctrl+D 添加 / 取消订阅；服务端确认后，黄色实心表示已订阅。
- 切换订阅号是切换云端列表，不是把旧列表搬过去。新建按钮先生成待用号码，点击“使用此订阅号”后才生效。
- 订阅号独立于发言饼干。此处实现的是支持通用订阅号的客户端协议，不是网页版绑定饼干的另一套订阅。

## 技能与设计决定

沿用本项目已采用的 `ui-ux-pro-max` 技能：延续紧凑三栏布局、同一图标体系和主题资源，状态变化同时通过星标、提示文字、可访问名称及底部状态呈现；请求期间禁用串星标，避免重复操作。订阅管理使用同一套 WPF UI 子窗口标题栏，正文可滚动，底部动作固定。

协议由 `research` 技能核对雾岛、霞岛公开源码，固定提交、字段与来源见 [订阅号研究](subscriptions-research.md)。本轮独立实现客户端逻辑，没有复制参考客户端代码。

不添加介绍性副标题。号码默认隐藏，只有主动点击复制才写入系统剪贴板。保留一行关于共用号码与访问权限的必要提示。浅深色均使用现有主题，不另建视觉风格。

## 接口及状态规则

| 操作 | 当前接口 |
| --- | --- |
| 读取 | `GET https://api.nmb.best/api/feed?uuid=…&page=…` |
| 添加 | `GET https://api.nmb.best/api/addFeed?uuid=…&tid=…` |
| 取消 | `GET https://api.nmb.best/api/delFeed?uuid=…&tid=…` |

增删虽使用 GET，仍按远程写操作处理：禁用缓存，不跟随重定向，不自动重试。只认可明确成功字符串。超时、网络中断、异常响应意味着结果未确认；下一次点击星标只重新读取，确认之后才允许再次增删，避免把已经成功的添加反向取消。

读取所有页并按串号去重，遇到明确空页才提交完整快照。单页不足 10 条不能证明读取完毕；中途失败、重复页、无效条目不会变成“未订阅”。客户端最多读取 1000 页，超出则报告同步未完成，这不是对服务端容量的承诺。界面每页展示 10 个订阅。

切换号码或浏览饼干时取消旧请求，并使用版本号拒绝迟到响应。号码由 Windows 当前用户 DPAPI 加密保存；请求 URL、正文和异常中可能携带的号码不写入错误提示。云端成员仅保留内存快照，本机历史继续保存阅读页码；不再存在 `UserState.Favorites`。
