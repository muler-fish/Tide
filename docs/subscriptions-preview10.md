# 潮汐 preview.10 · 多订阅号、临时缓存与加载反馈

日期：2026-10-23。用户选定“多订阅号 + 备注 + 切换，号码明文可见”。本轮继续使用 WPF + WPF UI，修复 preview.9 大量订阅时的等待问题。

## 需求与实现

| 问题 | 改动 |
| --- | --- |
| 900 多条订阅，每次打开都等很久 | 首次读取按页展示；后续页在后台继续。已有快照立即展示，5 分钟内再次进入不重复扫描 |
| 中文不能输入、保存后不可见 | 改用允许 IME 的普通 TextBox；中文、空格、符号与大小写原样保存、编码发送；管理窗和列表选择器明文显示号码 |
| 点击“我的订阅”像没反应 | 导航改为同步动作，网络同步不占用导航命令；侧栏悬停、按下、键盘焦点都有明确底色 |
| 重开数量归零、不知号码是否保存 | 保存可丢弃的订阅快照，启动先恢复数量和列表，再按时效更新；已有 preview.9 号码自动转为默认账户 |
| 多号码、备注、当前号码 | 管理窗可新增、编辑、复制、随机生成及移除本机号码记录；列表上方下拉框直接切号 |
| 切版和读串等待无反馈 | 显示进度动画与加载文字，第一次读串也能看到；最近结果有短时内存缓存，手动刷新仍请求网络 |

号码编辑只在按“保存”后生效，取消不影响现有设置。移除号码只移除本机记录，不调用云端删除订阅。保存备注后保留选择器中同一个账户对象，避免下拉框清空。

## 缓存边界

缓存只用于减少等待，不是额外的一套永久收藏。

- **普通版块与正文**：本次运行的内存缓存，30 秒有效；列表和正文各最多 40 个结果。关闭程序即丢弃。F5 / Ctrl+R 绕过缓存，成功发言后的刷新也绕过缓存。
- **订阅**：可跨重启使用的最近快照；5 分钟内导航复用，过期后先展示快照再后台同步，手动刷新立即检查。30 天未更新的快照不再使用，写缓存时清理过期文件。
- **首次导入**：读完第一页就可浏览，不等到最后一页；第一批及后续检查点落盘。已加载 10 个显示 `10+`，读到末尾才显示确切总数。
- **中途失败**：有完整旧快照时保留旧列表和数量，显示缓存时间；只有部分列表时明确标为部分缓存，不能推断不存在的串“未订阅”。
- **未知写入结果**：保留旧快照，并单独记录待核对串；不会把缓存当作远程确认，也不会自动重试写入。星标上的问号表示状态待核对。
- 缓存文件按订阅号和浏览饼干身份分开，切号 / 换饼干取消旧请求，旧响应不能覆盖新状态。目录名使用摘要，号码不会作为文件路径。
- 沿用原有正文离线缓存，不更改既有离线阅读范围。

缓存位于资料目录的 `subscription-cache/`，可在关闭程序后删除该目录来清理；号码、备注仍在设置中。界面明文显示不改变本机号码的 DPAPI 加密存储方式。号码输入上限 4096 字符，不接受换行和控制字符；这是客户端边界，不声称服务端长度限制。

## 诊断过程与技能

使用 `diagnosing-bugs` 建立可重复反馈：`Tide.Desktop.Tests.exe --subscription-cache <隔离输出目录>`。最小用例只返回第一页并阻塞第二页，检查首屏可见、导航可点击、重开恢复、中文号码可编辑。

旧版本的首屏、重开计数、号码显示三项失败，记录在 `artifacts/subscriptions-preview10-before/`；修正后通过。代码验证的原因分别是：完整分页返回后才更新集合；状态只存在内存；PasswordBox 隐藏文字并不适合中文订阅号。导航长期占用 TaskCommand 也使按钮在请求期间禁用，现已分离导航和同步。

使用 `ui-ux-pro-max` 的渐进加载、可离线回退、可见状态与输入反馈规则，执行本地 `progressive loading offline feedback` UX 查询。保留现有密度和图标，不新增宣传性文案；加载状态只展示必要进度。动画遵循 Windows 客户区动画设置，关闭动画时保留静态加载状态。

用户提供的插件串 `https://www.nmbxd.com/t/67024789` 及替代主站地址本轮无法通过网页读取，因此多号码交互按用户截图与确认实施，没有声称已核对该插件源码。

## 验证

- 29 项核心检查通过，包含中文、首尾空格、保留符号的精确 URL 编码，缓存隔离、过期与损坏回退。
- **950 条模拟订阅**：首屏在第二页仍阻塞时可用；完整扫描 96 次请求；连续四次再进入新增请求为 0；正文可以在扫描未完成时独立显示。
- 验证重开恢复 950 个计数、订阅号与备注持久化、选择器真实切换、旧号升级、多号码缓存隔离、刷新失败保留旧列表、修改备注后下拉框不清空。
- 验证普通列表及正文短时复用、手动刷新绕过；原有未知写入核对、迟到响应隔离、PO、标题栏、版块收藏和通知回归继续保留。
- 界面检查包含明文中文输入控件、IME 允许状态、浅深色截图、首次读串加载提示与鼠标进入后的侧栏底色。没有自动操作用户剪贴板。
- 测试使用隔离资料和固定模拟接口，没有读取用户的 900 多条实际订阅或使用个人饼干。模拟首屏耗时仅用于回归，不代表真实网络速度；第一次导入全部订阅仍需后台分页完成。

最终产物与测试目录见 [交付验证](verification.md)。主要代码为 `MainViewModel.Subscriptions.cs`、`MainViewModel.TemporaryCache.cs`、`SubscriptionWindow.cs`、`LocalStore.Subscriptions.cs`。
