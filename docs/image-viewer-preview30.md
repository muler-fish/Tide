# 看图末尾自动续页 · preview.30

对应 TODO 第 8 项（原 11）的追加要求，仍待用户验收。沿用 [preview.29](image-viewer-preview29.md) 的独立看图窗口与 QQ 参考布局，无“更多”菜单。

## 交互

- 从串阅读区打开图片，到达当前最后一张、且串还有后续页时，自动尝试获取下一页。当前图片保持显示，可继续缩放、拖动、旋转和保存。
- 加载时在画布底部显示小提示。新图片追加到图库，当前图片不主动切换；若用户已点“下一张”或按 →，加载成功后接到新图片。连点只保留一次切图意图，返回上一张会取消这个意图。
- 没有匹配图片的页自动跳过，单轮最多五页。仍有后续页时显示“这些页暂无图片”和“继续查找”，点击可接着找。
- 请求失败保留已有图库，显示原因及“重试”；也可用下一张按钮重试。失败后不自动反复请求，重试同一页并绕过短期缓存。重复旧页或错误页不会冒充新页。
- 已到接口报告的末页，或收到空回复页时停止，禁用下一张并提示“已到最后一张”。不会在末尾持续轮询新回复。
- 标题中的 `2 / 2+` 表示当前第 2 张、已取得 2 张且串还有后续页；取得全部范围后移除 `+`。

## 阅读状态、范围与缓存

图库从打开时已显示的图片开始，续页从正文已加载范围的最后一页向后进行。主窗口当前页码、列表内容、历史记录和滚动位置都不随看图续页改变。关闭看图窗口取消未完成请求，迟到结果不再更新窗口。

打开时的串号与 PO 筛选范围固定。主窗口随后切到别的串，已打开图库仍属于原串；更换浏览饼干后旧图库停止续页，提示重新打开，避免混用浏览身份。从串列表或引用弹窗进入仍是单张查看，不自动续页。

沿用正文 30 秒内存页缓存。看图新增页只在内存使用，不写正文磁盘缓存或阅读历史。原图按需下载，窗口内最多缓存三张、合计 32 MiB；关闭窗口释放。分页只获取发言及图片地址，不批量下载原图。GIF 仍显示首帧，保存保留原始动画文件。

## 实现与技能

沿用 `ui-ux-pro-max` 的加载状态、局部重试、避免重复请求和键盘可用性原则。续页提示覆盖在画布底部，不改变工具栏分布；窗口的局部深色主题继续独立于阅读主题。

- `src/Tide.Core/ImagePageCursor.cs`：独立页游标、成功后推进、重复页验证、图片去重与 PO 筛选。
- `src/Tide.Desktop/MainViewModel.ImageGallery.cs`：固定串与浏览身份，复用短期缓存与 API 页校验，保持正文状态不变。
- `src/Tide.Desktop/ImageWindow.cs`：末图触发、串行续页、无图页限次、加载/重试/末尾提示、切图意图和取消。
- `src/Tide.Desktop/MainWindow.xaml.cs`：仅串阅读区入口传入页游标。
- `tests/Tide.Tests/Program.cs` 与 `tests/Tide.Desktop.Tests/ImageViewerChecks.cs`：分页及真实窗口状态回归。

## 验收方法

1. 打开多页带图串，点击当前最后一张，观察底部加载提示；继续下一张应接到后续页图片。
2. 回看上一张或关闭看图窗口，确认正文仍在原位置。仅看 PO 时，后续图库也只包含 PO 图片。
3. 遇到无图页可自动略过；一轮五页仍无图时可继续查找。网络失败时重试，已有图片仍能查看。
4. 直接从正文末页打开最后一张，应该只显示到末尾提示，不出现加载条或重试按钮。

验证结果、实际发布体积和校验值见 [交付验证](verification.md)。固定数据测试覆盖边界与竞态；真实串的网络体验仍需本轮验收。
