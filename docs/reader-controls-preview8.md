# 0.2.0-preview.8 · 阅读操作与身份标记

日期：2026-10-23。按用户截图调整串正文工具栏、楼层头部和主题入口。

## 交互

- “只看 PO”复选框改为 `PO` 切换按钮：未选中为普通描边，选中为蓝色底色、蓝色边框和加粗文字；再次点击恢复当前已加载的全部回复。支持 Tab / 空格和辅助功能 Toggle 状态。
- 串收藏改为五角星按钮：空心为未收藏，黄色实心为已收藏；悬浮提示保留状态与 Ctrl+D。沿用本地保存，不改变既有收藏资料。
- 网页跳转改为“复制串链接”图标按钮；成功后状态栏显示“串链接已复制”，剪贴板不可用时显示可重试错误。
- 正文刷新使用与列表相同的 32 DIP 绿色图标底座，继续复用刷新命令及其禁用条件。
- “深色模式”使用与侧栏其他入口相同的图文间距；浅色时月亮为空心，深色时为黄色实心。文字保持固定，切换目标显示在悬浮提示中。

## 楼层头部

移除“PO · 串主”和“回应”文字。PO 使用蓝色标签，位于公开饼干左侧；主楼和 PO 的回复都显示。回复通过非空公开 UserHash 与主楼比较，不使用登录密钥，也不将空 ID 误认为同一作者。红名和 SAGE 仍独立判断。

日期在头部居中。头部小于 480 DIP 时，日期转到下一行居中，避免遮住饼干和楼号。楼号移至右上角，同时成为引用按钮；点击 `No.102` 会打开当前串的回复编辑器，插入 `>>No.102`。删除原“引用”文字按钮及正文底部重复楼号。

## 技能与实现

沿用 `ui-ux-pro-max` 的状态辨识、图标名称、焦点和窄窗口布局规范。WPF 查询 `toggle selected state` 返回的命令可用性规则适用于刷新和收藏；控件继续使用命令的 CanExecute。PO 颜色使用单独语义资源，在浅色、深色和高对比度主题中更新。

主要入口：`MainWindow.xaml`、`MainWindow.xaml.cs`、`PostIdentity.xaml`、`MainViewModel.cs`、`App.xaml`、`App.xaml.cs`。`ReadPost.IsPo` 表示当前串中的发言人身份；`IsOriginal` 独立表示主楼。

## 订阅命名

使用 `research` 指定的研究子代理，核对公开的一手源码，结果见 [订阅号调研](subscriptions-research.md)。通用订阅号服务与本地收藏不同：本版星标仍保留本地收藏语义。后续接入订阅号导入 / 生成、服务端增删和同步失败处理后，再增加“我的订阅”，不把本地改名当作已支持云同步。

## 验证

`ReaderControlsChecks` 使用隔离资料和固定 GET 响应检查：PO 实际过滤 / 恢复、主楼及 PO 回复标签、星标状态与保存、月亮状态与主题保存、900 / 1060 / 1460 DIP 宽度下的日期和楼号、点击楼号打开正确引用编辑器、正文刷新请求。测试不会发送帖子，也不读取或覆盖用户剪贴板；复制链接处理经代码核对，未自动实测系统剪贴板。

独立检查参数为 `--reader-controls`，完整界面回归也会执行该检查。最终结果、截图和发布校验值见 [交付验证](verification.md)。旧版 preview.7 保留。
