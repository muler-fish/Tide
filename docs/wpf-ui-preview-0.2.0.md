## 交付与运行

- 试用版：`release/0.2.0-preview.1/Tide.exe`，Windows x64、自包含单文件。

- `licenses/` 保留该 NuGet 包的 MIT 许可和第三方声明；`SHA256SUMS.txt` 记录最终 EXE 校验值。

## 技能与设计依据

本轮使用 `ui-ux-pro-max SKILL.md`，结合用户截图、此前已确认的功能要求，以及实际 WPF 控件表现做取舍。

执行了设计方向检索 `desktop reader compact minimal`、更窄的 UX 检索 `compact desktop reading` 和 WPF 栈检索 `ControlTemplate styling`。通用设计检索返回的营销页 Hero、CTA 与西文字体不适用于匿名版，未采用；采用的建议是优先隐式样式、尽量保留成熟控件模板、状态不能只用颜色表达，以及保证键盘焦点和可读对比度。

组件库负责基础控件与窗口行为，阅读界面仍按匿名版的高频场景单独设计，不套用 Gallery 的整页卡片布局。前期比较见 [组件选型](ui-library-options.md) 和 [技术路线比较](ui-framework-alternatives.md)。

## 本轮界面变化

| 区域 | 实现 | 用途 |
| --- | --- | --- |
| 主窗口 | `FluentWindow + TitleBar`，48 DIP 高的一体标题栏 | 标题、跳串、发串与窗口按钮位于同一行，减少重复顶部区域 |
| 标题栏 | 中间留拖动区域；输入和按钮使用库的交互内容区域 | 拖动、双击最大化及工具按钮不会争抢命中区域 |
| 左侧 | 默认宽 184 DIP；统一 Fluent 图标；版块分组默认收起 | 将空间留给串列表和正文，保留原有导航 |
| 串列表 | 默认宽 320 DIP；缩略图在文字右侧，72 DIP 高；空摘要不占位 | 增加同屏内容，同时保留串首图片、饼干、SAGE 与阅读进度 |
| 正文 | 连续阅读流和细分隔线，取消逐条大圆角卡片 | 明确楼层边界，减少重复装饰 |
| 正文边距 | 列表两侧 24 DIP，楼层右侧另留 12 DIP | 避开库的覆盖式滚动条，保证引用按钮、楼号和正文可见 |
| 通用输入与按钮 | WPF UI 的 TextBox、Button 及基础控件样式 | 保留库提供的焦点、禁用、悬停和按下状态，减少自制模板 |
| 主题 | 中性浅灰 / 深灰底；青绿仅用于主要操作、饼干和选中态 | 降低大面积品牌色对阅读的干扰 |

初始期望尺寸仍为 1280 × 800 DIP；主窗口最小尺寸改为 900 × 600 DIP。首次显示前继续按所在显示器工作区和 DPI 收小、调整最小尺寸并居中。上述逻辑不等于保证任何极端小工作区都能完整容纳三栏内容。

字体使用系统字体：界面 `Segoe UI Variable / Microsoft YaHei UI / Segoe UI`，中文正文沿用 Microsoft YaHei UI，字号设置仍为 13–24 DIP，默认 16。没有下载或复制 Windows 字体文件。

## 集成中发现并修正的问题

1. 库的 ListBox 模板不使用原来的 Padding。首轮截图出现正文贴边，改用列表外边距，并给覆盖式滚动条单独预留空间；900、1060、1280 DIP 窗口验证楼号位置。
2. 主按钮在主题切换后出现深色字与深色底组合。统一更新库的主按钮背景、悬停、按下和文字资源，继续使用原控件模板；加上两种主题、三种状态的对比度检查。
3. 无摘要的串项产生不必要空白。摘要为空时折叠，保留有内容时的两行摘要。
4. 原窗口检查读取 DWM 系统标题栏位置，不能证明新标题栏按钮可见。源代码测试读取实际控件边界；最终 EXE 检查通过 UI Automation 查找三个真实标题栏按钮。

## 保留的功能和实现边界

`Tide.Core`、接口及持久化逻辑没有因换库重写。保留版块 / 时间线、串号跳转、引用、只看 PO、分页累积、收藏、历史、离线缓存、图片与无图模式、字号、颜文字换行，以及草稿和发送前预览确认。

列表仍使用虚拟化和回收；图片控件继续在换绑 / 卸载时取消旧请求并隔离过期结果。未进行长串滚动性能基准，不能据此声称性能提升。

这次一体标题栏应用于主窗口。发言、饼干管理、引用与原图等子窗口继续保留系统标题栏，通用按钮和输入使用新样式。没有为追求外观而同时重写所有弹窗。

发言不会自动发送或自动重试；验证过程没有导入真实饼干，也没有提交真实发言。

## 仍需实际使用确认

自动化在当前 1920 × 1080、125% 缩放的机器上运行。30 组工作区 / DPI 是尺寸计算测试，没有实际切换系统分辨率，也没有真实跨显示器拖动。中文 IME 候选窗、完整 Tab 操作路径、Windows 11 Snap 布局弹层、系统高对比度模式和干净机器启动尚未逐项实测。高对比度已有系统颜色回退，但不把配置存在视为验收通过。

没有使用真实饼干发串、回帖或上传图片；现有模拟接口覆盖不替代真实账号的首次使用验证。其他产品边界沿用 [README](../README.md)。
