# 串列表预览排版 · preview.24

对应 TODO 第 3 项（原 12），待用户验收。本轮补充意见包括饼干、SAGE 标签与正文红绿强调文字的饱和度；按钮、侧栏选中背景和 PO 配色保持不变。

## 排列与显示规则

```text
饼干  日期  板块                          回复数
SAGE（如有）
标题（如有）
名称（如有）
正文：按栏宽折行，最多八行
阅读进度（如有）
```

- 不再把正文第一行当作标题，也不再把剩余正文合并成一行。空标题/名称及接口的默认“无标题”“无名氏”不占位置；有内容的标题、名称各占一行，过长时省略。
- 标题沿用 14 DIP 加粗，名称 13 DIP 次要文字色，预览正文为 14 DIP、1.5 倍行高。第 4 项的字号层级要求保持在 TODO 中供单独确认，本轮不提前划掉。
- 元信息左侧按“饼干 → 日期 → 板块”排列，回复数固定右对齐。窄栏放不下时左侧换行，不压缩饼干或遮住回复数。preview.24 日期展示年月日；preview.25 起[增加时分、当年省略年份](date-time-preview25.md)，串内精确到秒。提示保留原始时间；串号可在条目提示中查看。
- 原始换行、缩进、空行、加粗、斜体、下划线、受支持的红绿强调文字和彩色 emoji 均保留。按真实栏宽排版，正文最多八行；短正文随内容收缩，空正文折叠。标题、名称、元信息和缩略图不计入正文八行。
- 缩略图仍在正文右侧，无图模式保留“显示这张图片”。没有增加预览内的滚动条，点击预览仍打开当前串；完整正文中的链接和图片沿用既有操作。
- 防剧透设置继续同步预览：关闭时保留原始 `[h]…[/h]`，开启时列表使用 `[隐藏内容]` 摘要占位，打开串后使用已验收的黑条。
- 板块、时间线、订阅、历史共用这份列表模板，保留原有阅读进度、列表虚拟化和末项悬浮按钮留白。

## 颜色范围

独立语义颜色用于身份标签与正文强调。没有通过改动全局 `AccentSoft`、`Danger` 等资源连带调整选中行或操作按钮。

| 内容 | 浅色背景 / 文字 | 深色背景 / 文字 |
| --- | --- | --- |
| 普通饼干 | `#BDEAD8` / `#086147` | `#20533F` / `#8DE0BC` |
| 红名饼干 | `#FFD2CC` / `#982F2B` | `#612F34` / `#FFB7AD` |
| SAGE | `#D5102B` / 白色 | `#D91B37` / 白色 |
| 正文绿色强调 | 原正文底色 / `#007548` | 原正文底色 / `#42D995` |
| 正文红色强调 | 原正文底色 / `#C51D35` | 原正文底色 / `#FF6B7B` |

身份标签文字对比度均超过 5:1，正文强调文字在对应正文背景上的对比度不低于 4.5:1。高对比度模式使用系统文字/背景色。红名与 SAGE 独立判断，颜色不代替标签文本。

## 实现与技能

使用 `ui-ux-pro-max`（`ui-ux-pro-max`）。针对紧凑标签换行查询，首轮泛化结果重试为 `chip collection reflow`，采用“整体换行保留标签”的通用原则，映射到 WPF `WrapPanel`；同时检查行高、截断、键盘操作、深浅主题和虚拟化。

- `PostCard` 分离真实标题、名称与正文摘要；右侧阅读标题继续保留旧规则，等 TODO 第 5 项处理。
- `PostPreview` 使用轻量 `TextBlock` 和现有受限 HTML 格式映射，按字号设置八行上限，不再先按固定字符数截断。保留空白；不执行 HTML、脚本或任意远程样式。
- `PostIdentity.ShowSage` 让列表把 SAGE 单独排列；正文、引用的身份行结构保持原样。
- `Cookie*`、`AdminCookie*`、`PostGreen`、`PostRed` 资源把本次调色与其他界面色分开。

## 验收建议

1. 查看有/无标题、有/无名称、SAGE 和普通串，确认顺序和空字段折叠。
2. 对比短正文、长正文、多行图案：空行与缩进保留；预览最多八行，短串不留大空白。
3. 拖动中栏宽度，确认元信息不重叠，回复数右对齐，正文随宽度重新折行。
4. 深浅模式各看一次普通饼干、红名、SAGE 及正文红绿文字，判断饱和度是否合适。
5. 在列表中打开串，确认缩略图、阅读进度、连续续载及悬浮按钮仍正常。
