| 位置 | 名称 | 内容 |
| --- | --- | --- |
| 左侧 | 板块导航栏 | 板块分组、收藏板块及导航入口 |
| 中间 | 串列表区 | 当前板块、时间线、订阅或历史中的串预览项 |
| 右侧 | 串阅读区 | 打开的串及其主楼、回复 |

## 本轮变化

串阅读区固定头部标题使用 `No.串号`，上方只显示板块名称，去掉重复串号与回复数量。原帖实际标题移到第一页主楼正文上方，保留加粗及换行；“无标题”不显示，也不再以正文第一行补标题。切换主题、防剧透、字号及刷新后固定头部仍使用串号。

串列表区的正文与标题共用阅读设置中的字号（13–24 DIP），标题加粗，作者比正文小 1 DIP 并使用次要文字色。板块、时间、回复数、饼干和 SAGE 等元信息保持现有字号。正文按当前字号重排，每行 1.5 倍行高、最多八行；短内容和空内容继续自然收缩。板块、时间线、订阅和历史共用同一个预览模板。

设置中的标签改为“正文字号（含串列表预览）”，调整即时生效，沿用原设置保存与重启恢复。无需额外开关或另一套字号配置。

## 实现与设计依据

使用 `ui-ux-pro-max`，查询 `text scaling font hierarchy`。采用一致字号层级、文字放大后重新排版及窄栏可读性检查，沿用项目现有 WPF UI 组件和 MiSans 字体。

`ReadingFontSize` 统一驱动预览与正文，`PreviewAuthorFontSize` 派生作者字号；原有 `PostPreview` 随字号更新八行高度，无固定像素高度。`ReaderTitle` 和 `ReaderMeta` 仅保留定位信息，`OriginalTitle` 在主楼显示并遵循已有防剧透纯文本规则。原始帖子内容和缓存结构不变。

## 验收

1. 打开有标题和无标题的串：固定头部为串号，上方仅板块名；第一页主楼保留实际标题，无标题不留空行。
2. 在阅读设置调整正文字号：中间预览和右侧正文同时变化，标题加粗、作者稍小；关闭设置后继续浏览及重启，字号保持。
3. 缩窄串列表区并放大字号：长正文仍最多八行，短正文不撑满八行，元信息和悬浮按钮可用。
