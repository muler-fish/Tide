## 使用方式

- 串阅读区右键发言，显示“复制”“回应”。有文字选区时复制选区，否则复制这条发言的可见正文，保留换行和 emoji；未展开的剧透仍为遮罩。“回应”打开原有编辑器并插入该楼号，不自动发送。Tips 仅提供复制。
- 串列表区右键“屏蔽此串”。右键不选中或打开该串，也不改变右侧串号、页码和阅读位置。屏蔽适用于本机板块、时间线、订阅和历史的串列表；不取消云端订阅、不删除历史，明确输入串号仍可打开。
- 阅读设置 → 屏蔽管理：显示串号与标题摘要，逐项取消屏蔽。当前已加载项目立即重新出现，不需要联网刷新。屏蔽列表保存在资料目录，重启后恢复。
- 板块导航行右键“收藏板块”或“取消收藏板块”，与现有星标共享状态。收藏操作不切换当前板块。
- 复制串链接的成功气泡显示在按钮附近；复制发言、屏蔽、板块收藏、订阅操作也有气泡反馈。成功约 2.5 秒后消失。
- 列表与正文错误在各自区域上方显示，替代原来的顶栏横条，不挤动布局。错误约 8 秒后消失，也能手动关闭；鼠标停留或键盘焦点进入时暂停倒计时，长文案可以滚动查看。相同区域的新提示替换旧提示；两个区域可以同时显示各自的错误。

## 设计及边界

继续使用 `ui-ux-pro-max`，采用 WPF 原生 ContextMenu/MenuItem，沿用现有 WPF UI 主题；保留菜单键、选区复制和键盘焦点。没有新增图标或 UI 依赖。

屏蔽采用 `ListCollectionView` 显示过滤，底层已加载集合仍用于页码、去重、历史分批及订阅同步。这样屏蔽整页不会误判已到底，也不会把订阅总数变成零；全页隐藏时提供“加载下一页”。取消屏蔽只刷新视图，不清缓存。

气泡使用窗口内浮层，不产生置顶窗口、不获取焦点，也不阻止区域内其他位置的点击。开始新请求时清除该区域旧提示；切到其他窗口或关闭主窗口时收起浮层。原有加载条、续页失败重试入口、编辑器表单校验和串预览小窗的局部错误保留。底部仍可显示加载/离线等状态，交互成功反馈不再只依赖底部小字。

只运行 `Tide.Desktop.Tests.exe --context-actions`，使用隔离资料目录和固定 API 返回，不读取真实饼干、不发送线上发言或修改真实订阅。
