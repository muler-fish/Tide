# preview.22：黑条防剧透与阅读开关

日期：2026-10-27。TODO 第 5、6 项已获用户确认并划掉。本轮对应第 8 项，待用户验收；第 20 项链接跳转仍只记录、不实施。

## 使用

- 正文中的成对 `[h]…[/h]` 显示为黑条，点击展开当前片段。也可用 Tab 聚焦后按 Enter 或空格展开。多段内容分别控制，长段落随阅读宽度换行。
- 阅读设置 → 防剧透 → **启用防剧透**，preview.22 默认开启，修改立即生效并保存。preview.23 起默认关闭，已保存的开关状态保留，见 [后续调整](floating-actions-preview23.md)。
- 关闭后显示 `[h]防剧透文本[/h]`，不剥离方括号标签；重新开启会重新遮盖。普通 HTML 格式、换行和 emoji 仍使用原有渲染方式。
- 主阅读区（含 tips）、引用、版规与发送预览共享开关；已打开和后来打开的正文窗口均同步。
- 串列表、阅读标题和草稿摘要遵循同一开关：开启时继续用 `[隐藏内容]` 简短占位，关闭后显示带 `[h]` 标签的摘要。列表布局不在本轮扩展，相关调整仍按 TODO 第 12、13 项处理。
- 发言输入框始终保留原始文本。开关不修改草稿、接口数据或实际发言内容；普通站内/站外链接的跳转规则保持不变。

## 行为边界

黑条由遮罩字符构成，未展开的秘密文字、链接与彩色 emoji 不进入可读文档。因此选中黑条、复制或键盘访问时不会提前带出隐藏正文；复制未展开区域得到的是遮罩。展开后按当前显示内容正常复制。

展开后恢复格式、链接和 emoji；不会把链接放进另一层可点击链接中。单次展开只属于当前显示实例，重载正文后重新遮盖。修改字号和主题不会主动收起已展开内容；关闭再开启防剧透则重新遮盖。

兼容大小写 `[H]`；空段保留一个可点击黑条；不完整的单边标签原样显示。遮罩按可见字素数量近似长度，**不保证与展开后的文字逐像素等宽**，展开长内容可能重新排版。磁盘中的原始内容仍按既有缓存规则保存。

## 实现与技能

继续使用 `ui-ux-pro-max`（`ui-ux-pro-max`）关于可访问名称、键盘入口、明确状态及深浅主题一致性的建议；沿用 WPF 原生 Hyperlink 的键盘与自动化支持，并补充空格操作。

- `UserState.HideSpoilers` 默认 `true`，兼容旧资料；开关立即持久化。
- `PostBody.HideSpoilers` 通过动态资源同步所有正文入口。仅开关值改变时重绘，不因其他外观设置重复重绘。
- `PostBody` 在渲染前隔离隐藏片段，未展开时只渲染黑条；展开后复用受限 HTML 渲染器，保留现有安全链接约束。
- `PostCard` 改为可通知的显示对象，仅更新标题/摘要，不重建列表集合或触发网络请求；后续加载的卡片也读取当前设置。

## 验证与验收

核心检查覆盖旧资料默认开启、关闭设置持久化及原始标签保留。`--spoilers` 专项覆盖深浅主题、复制、隐藏 emoji、鼠标/键盘展开、多个片段、格式和链接、主阅读区及新旧窗口同步、列表摘要、窄窗口、空段、不完整标签与控件复用。结果与发布包体积见 [交付验证](verification.md)。

验收步骤：

1. 退出旧版，打开 `release/0.2.0-preview.22/Tide.exe`。
2. 浏览含 `[h]…[/h]` 的正文，确认显示黑条且点击能展开。
3. 在阅读设置中关闭「启用防剧透」，确认显示原文和标签；重新开启，确认再次遮盖。重启程序后检查开关是否保留。

可用发言编辑器插入「防剧透」标记后进入发送预览观察；无需点击确认发送。第 8 项仅在用户确认后划掉。
