# 气泡动画与停留时间

日期：2026-10-29。版本：0.2.0-preview.34。按用户对第 11、12 项的新反馈修订，仍与第 10 项联合待验收。

- 成功气泡从对应按钮或操作位置向上浮出，约 220 ms 到位，停留 500 ms，再用 120 ms 淡出。复制从复制按钮出发，订阅从星标出发；收藏入口或屏蔽行即使随操作消失，也使用操作前记录的位置。
- 错误气泡从所属区域上方下滑，约 240 ms 到位，停留 5 秒，再淡出；错误位置不跟随成功提示的按钮起点。
- 两种气泡均取消关闭按钮。悬停及键盘焦点不再延长停留时间。长错误仍可滚动查看。
- 不占布局、不夺焦点；同区域新气泡替换旧气泡，旧动画完成回调不能删除新提示。切换窗口或关闭时清理动画。
- 沿用 `ui-ux-pro-max` 的位移/透明度动画与缓出原则。尊重 Windows 动画设置：关闭系统动画时直接显示，仍按 0.5 秒 / 5 秒收起。

## 实现

`FeedbackOverlay.cs` 统一处理 TranslateTransform、Opacity、停留和取消；`MainWindow.Feedback.cs`、`MainWindow.ContextMenus.cs` 和 `ForumFavoriteToggleButton.cs` 传递操作位置。位置在动作前取快照，避免收藏行消失后找不到原按钮。动画首帧先设置起点，等待 WPF 动画时钟推进，避免先闪到终点。

## 最小验证

仅执行 `--feedback-motion`，记录在 `artifacts/feedback-motion-preview34-final/`：退出码 0、stderr 为空。验证复制按钮实际调用、取消收藏后起点保留、成功向上/错误向下、到位及停留时间、无关闭按钮、悬停不延长、重复触发不误删新提示、无焦点抢占、无动画分支和关闭清理。检查固定数据和隔离资料，无真实发言或订阅写入。

首轮检查发现动画时钟启动前未设置基准坐标，已修正；第二轮关闭测试需等待 WPF 的异步 Unloaded，调整测试等待后最终通过。原 `--context-actions` 的旧计时与关闭断言已同步新要求，但本轮不重跑整套右键/屏蔽测试。没有运行无关全量巡检。
