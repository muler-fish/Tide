## 操作与界面

发串和回复编辑器均在原有快捷颜文字旁增加“更多颜文字”。窗口左侧是虚拟化列表，右侧原样预览；上方按分类或名称、缩写、颜文字搜索。分类含网页常用、日常、开心、亲近、惊讶、难过、生气、围观、搞怪、动物、组合符号和大型。

- 单击选择后预览，点击“插入”或按回车插入；也可双击列表条目。Esc 或“取消”返回编辑器，不改变正文。
- 保留打开前的光标与选区：有选区时替换选区，否则在光标处插入，光标移到末尾。插入可一次撤销，沿用草稿保存。
- 不足 10000 字上限的剩余空间时，拒绝整个图案并提示，不截断图案或改动原文。Windows 文本框使用 CRLF 换行，插入前统一换行形式后计算长度。
- 预览不自动折行，窄窗口可横向和纵向滚动。使用系统现有字体，不安装新字体。原资料本身的排版差异或系统字体缺字不在本轮保证范围内；TODO 第 7 项仍独立待办。

使用 `ui-ux-pro-max`，采用可见标签、键盘操作、模态关闭后恢复焦点、列表虚拟化和浅色/深色一致性。保持现有 WPF UI；检索到的键盘导航建议只按桌面控件语义使用，没有套用 Web 专用实现。

## 代码与验证

- `tools/Build-Emoticons.py`：从资料副本生成 `Assets/emoticons.json`，同时输出数量和来源 SHA-256；此工具不是日常编译依赖。
- `EmoticonCatalog.cs`：内置资源加载、分类与搜索，原始文本不可变。
- `EmoticonWindow.cs`：选择、预览、键盘与滚动；`ComposerWindow.cs`：选区恢复、完整插入、长度检查和草稿联动。
- `EmoticonChecks.cs`：库完整性、缩写/中文搜索、原样换行、选区/光标/撤销、空结果、取消、草稿、上限、虚拟化、浅深色及最小尺寸检查。

## 验收步骤

1. 打开发串或参与回应 → 更多颜文字，搜索“抱抱”或 `vbb`，插入到正文中间；再选中文字后插入，确认替换位置正确。
2. 选择“大型”，搜索“举高高”或“催更”，检查预览与插入后的内容；缩小窗口时可以滚动预览。
3. 取消选择不改正文；关闭编辑器后从草稿箱继续编辑，颜文字应保留。
