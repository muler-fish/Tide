## 使用和交互

- 默认开启。在设置 → 滚动 → 惯性滚动中开关，立即生效并保存，重启后保持选择。
- 鼠标滚轮推动页面后短暂滑行、逐渐减速；连续滚动可积累位移，反向滚动立即改变方向。
- 作用于版块目录、串列表（含订阅和历史）、正文，以及子窗口的外围内容滚动区域。
- 点击、键盘操作、切换串或版块、窗口失焦、关闭选项都会停止当前惯性；拖动滚动条保持直接定位。
- 页面边缘不越界、不露白；到底仍触发已实现的自动续载，追加后保留原来的阅读位置。
- 编辑框、下拉框和可独立滚动的嵌套区域使用原生行为；Ctrl＋滚轮图片缩放继续由图片窗口处理。未替换触摸或触控板系统手势。
- Windows 关闭界面动画时使用普通滚轮行为。可在应用内单独关闭惯性，无需修改系统设置。

## Skill 与实现

本轮使用本机 `ui-ux-pro-max`，检索滚动动画、可打断性和减少动画相关指导。采用统一设置、有限滑行距离、尊重系统动画偏好，并保留原生输入行为。设置区沿用 WPF UI 的复选框和现有排版，只新增“滚动 / 惯性滚动”一组，说明放在悬停提示中。

主要代码：

- `src/Tide.Desktop/ScrollMotion.cs`：独立于 WPF 的临界阻尼曲线，按实际帧间时间计算；快速输入的待滚距离限制为两个视口，反向输入丢弃旧方向惯性。
- `src/Tide.Desktop/InertialScroll.cs`：附加行为，识别输入来源、调用现有 ScrollViewer；仅在滑行期间订阅渲染事件，关闭、卸载或失焦时取消，不在后台持续驱动动画。
- `MainWindow.xaml`、`ChildWindow.cs`、`Dialogs.cs`：绑定共享开关；子窗口沿 Owner 找到主窗口，同步外围滚动设置。输入框内部不绑定该行为。
- `Models.cs`、`MainViewModel.cs`：保存布尔选项。旧状态文件缺少字段时默认开启，已保存的关闭状态会恢复。
- `IncrementalScroll.cs`：近底部检测改为 90 ms 节流，避免逐帧滚动把续载检测无限推迟。原有请求串行、末页停止和失败重试规则沿用。
