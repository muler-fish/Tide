## 界面行为

| 正在查看的内容 | 发串 | 回应 |
| --- | --- | --- |
| 板块或时间线列表 | 中栏右下角，铅笔图标 | 由右侧是否打开串决定 |
| 订阅、最近浏览列表 | 隐藏 | 右侧仍有串时保留 |
| 右侧尚未打开串 | 不影响中栏 | 隐藏 |
| 右侧已打开串 | 不影响中栏 | 阅读区右下角，回应箭头 |
| 正在替换右侧串内容 | 不影响中栏 | 暂不可点击，避免回应旧串 |

两个按钮为 48 × 48 DIP，沿用主操作色和 WPF UI 图标、悬停及键盘焦点反馈；工具提示及自动化名称分别为“发一个串”“参与回应”。它们是列表的同级控件，固定在各自内容区右下角，滚动不会改变位置；调整窗口或分栏宽度时跟随内容区边缘。顶部原发串入口和阅读区底栏原回应文字按钮移除。

只在列表末项下方增加 80 DIP 可滚动留白，使最后一条内容可以完整滚到按钮上方；续页后留白转移到新的末项。保留列表虚拟化与双向续载机制。中途内容经过按钮下方时仍可继续滚动查看。

发串仍采用当前普通板块；时间线没有单独发串接口，沿用原编辑器的综合版1默认目标。回应仍指向当前打开的串，发送前的预览与确认流程保留。

## 防剧透默认值

新资料以及缺少 `HideSpoilers` 字段的旧资料默认关闭，正文显示原始 `[h]…[/h]` 标签；已经明确保存的设置继续沿用。若 preview.22 已保存为开启，需在阅读设置中关闭一次，此后会记住关闭状态。

开启后的黑条、点击/键盘展开和多个正文窗口同步行为见 [防剧透说明](spoilers-preview22.md)。本轮没有改动原文、草稿或缓存内容。

## 实现与技能

使用 `ui-ux-pro-max`（`ui-ux-pro-max`）检查固定控件遮挡内容、键盘可访问性、图标按钮名称和主题一致性；适配 WPF 原生控件体系。

- `MainViewModel.ShowNewThreadAction` 根据当前列表类型更新；回应沿用 `HasThread` / `CanInteractThread`，点击处理器也检查有效状态。
- `MainWindow.xaml` 定义共享悬浮按钮样式，两个按钮均放在滚动控件之外。
- `FloatingActionInsetConverter` 根据集合末项、数量和显示条件移动底部留白，不写入帖子数据。
- `UserState`、`PostBody`、`PostCard` 的防剧透默认值统一改为关闭；不覆盖已保存设置。

## 验收

1. 在板块或时间线滚动，点击中栏铅笔，确认打开对应板块的发串表单。
2. 打开串并滚动，点击右下角回应箭头，确认编辑器显示当前串号。
3. 切换到订阅、历史，确认中栏铅笔隐藏，右侧仍打开的串保留回应按钮。
4. 将列表和正文滚到最后，确认末条内容可完整显示在按钮上方；缩小窗口或拖动分栏后按钮仍在对应区域。
5. 阅读设置关闭防剧透后重启，确认开关保持关闭；重新开启后仍显示可点击的黑条。
