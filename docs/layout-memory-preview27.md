## 操作与保存

- 标题栏左侧菜单按钮收起/展开板块导航栏，也可按 `Ctrl+B`。收起后按钮仍在原位置，原导航栏与对应分隔条不占宽度；展开恢复原栏宽。
- 两条分隔条均可拖动，或 Tab 聚焦后用左右方向键调整。串列表区不再固定限制为 480 DIP，最大宽度由窗口剩余空间决定；正常尺寸下为串阅读区至少保留 280 DIP。
- 保存主窗口普通尺寸、最大化状态、板块导航栏显隐、导航栏宽度和串列表区宽度，串阅读区使用剩余空间。最小化不覆盖普通尺寸或最大化状态。
- 尺寸变化节流 500 毫秒保存；切换导航栏、调整分隔条完成和关闭窗口时立即补存。沿用当前资料目录的 `state.json`，不同资料目录互相独立。

临时缩小窗口会收窄当前分栏，但保留用户设置的宽度；重新放大后恢复。导航栏收起不会把已保存宽度改成零。新资料和旧版缺少布局字段的资料使用原默认布局。恢复时以当前显示器工作区和 DPI 为准，尺寸过大时收缩并居中，避免标题栏落到屏幕外；不恢复屏幕坐标。临时弹窗继续按其原规则安排大小。

## 实现与技能

使用 `ui-ux-pro-max`，查询 `navigation state preservation keyboard toggle`，重点检查显隐入口始终可达、键盘操作、焦点与窄窗口。沿用 WPF UI 图标、主题和按钮反馈。

`WindowLayoutState` 保存 DIP 尺寸并校验非法值；`MainLayoutController` 管理视图事件、实际分栏适配与节流保存。只有用户完成分隔条调整才更新偏好栏宽，窗口缩小时的临时适配不覆盖它。`WindowPlacement` 保留首次启动的留边逻辑，恢复已有尺寸时仅限于工作区，避免重启后重复缩小。

不清空正文、串列表、阅读记录或网络缓存。窗口关闭时停止计时器并解绑事件。

## 验收

1. 拖宽串列表区，超过旧上限；关掉再启动，确认窗口尺寸与栏宽恢复。
2. 收起板块导航栏并重启，再展开，确认原栏宽恢复，列表和阅读内容仍可使用。
3. 缩窄再放大窗口，确认串阅读区保留空间、栏宽能恢复；最大化后关闭，重开仍最大化，点还原恢复普通尺寸。
4. 用 Tab、方向键和 `Ctrl+B` 操作，核对深浅模式下按钮反馈。
